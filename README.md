## Sobre o Projeto

O **Merge Sort** é um dos algoritmos de ordenação mais eficientes e amplamente estudados na Ciência da Computação. Ele utiliza a estratégia de **Divisão e Conquista** (*Divide and Conquer*) para ordenar um conjunto de dados.

### Funcionamento do Algoritmo:

1. **Divisão:** O vetor original é sucessivamente dividido ao meio até restarem subvetores de apenas 1 elemento (um vetor unitário já se encontra ordenado).
2. **Conquista:** Os subvetores menores são ordenados de maneira recursiva.
3. **Combinação (*Merge*):** As metades ordenadas são intercaladas em ordem correta até recompor o vetor completo e totalmente ordenado.

## Complexidade do Algoritmo

| Caso | Complexidade Temporal |
| :--- | :--- |
| **Melhor Caso** | $O(n \log n)$ |
| **Caso Médio** | $O(n \log n)$ |
| **Pior Caso** | $O(n \log n)$ |
| **Espaço Adicional** | $O(n)$ |
